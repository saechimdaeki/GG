# 냥난리 · Cat Chaos — Game Brief

## 한 줄
주인이 출근한 사이, 고양이가 되어 퇴근 전까지 집을 최대한 어지르는 3인칭 물리 샌드박스. 한 판 10분.

## 재미의 핵심
- 아무 생각 없이 부수는 시원함: 컵을 툭 쳐서 떨어뜨리고, 화분을 엎고, 휴지를 굴려 푼다.
- 고양이다운 움직임: 2단 점프로 식탁 → 조리대 → 냉장고 위까지 올라간다.
- 점수와 콤보: 2.5초 안에 사고를 이어 치면 배율이 x5까지 오른다.
- 마지막 반전: 주인이 오기 직전 내 방석에 숨으면 "시치미 보너스" x1.5.

## 한 판의 흐름
1. 타이틀: 클릭하면 주인 출근, 타이머 10:00 시작.
2. 집 탐색: 거실·주방·침실·욕실·현관 5개 공간. 오른쪽에 "오늘의 말썽" 8개.
3. 남은 60초: 주인 문자 알림, 해가 저녁빛으로 바뀌고 마지막 10초엔 초침 소리.
4. 0초: 열쇠 소리 → 현관문이 열리고 주인 시점으로 집을 본다 → 주인 한마디.
5. 결과: 등급(D~S), 점수, 깨뜨린 물건·휴지 길이 등 집계. R로 다시 하기.

## 빌런: 로봇청소기
- 1분 15초 뒤 첫 출동, 이후 2분마다(동시에 최대 2대, 남은 시간 20초 미만이면 안 나옴).
- 가장 가까운 바닥 조각·흙·휴지 자국을 찾아가 빨아들임. 하나당 -10점.
- 냥펀치 3방이면 뒤집혀서 멈춤: +500점, 말썽 목표 "로봇청소기 뒤집기".
- 벽에 막히면 후진하고 방향을 틈.

## 점수 규칙 (값은 `Assets/Resources/tuning.json`)
| 사고 | 기본 점수 |
|---|---|
| 물건 쓰러뜨림 / 큰 물건 쓰러뜨림 | 30 / 120 |
| 떨어뜨림 (원래 높이보다 0.4m 아래) | 50 |
| 깨뜨림 (컵·접시·꽃병·액자 등이 2.2m/s 넘게 부딪힘) | 120 |
| TV 넘어뜨리기 | 400 |
| 화분 엎어 흙 쏟기 | 80 |
| 휴지 풀기 | 1m당 25 (콤보를 올리지 않고 타기만 함) |
| 가구 긁기 | 1초당 40 (〃) |
| 로봇청소기 뒤집기 | 500 |
| 로봇청소기가 조각 하나 치움 | -10 |
| 말썽 목표 달성 | 300 (콤보 미적용) |

획득 점수 = 기본 점수 × 콤보(1~5). 등급: 1,500 C · 4,000 B · 8,000 A · 14,000 S.

## 조작
WASD 이동 · Shift 우다다 · Space 점프(공중 1회 더) · 왼쪽 클릭 냥펀치 · 오른쪽 꾹 발톱 긁기 · Q 야옹 · Esc 일시정지

## 기술
- Unity 6000.6.9f1 URP, 씬은 코드로 생성(`Game` 하나만 씬에 있음).
- 에셋(전부 CC0): Quaternius 큐브 고양이, Kenney Furniture Kit, Poly Haven 바닥·벽 텍스처와 상자.
- 소리는 파일 없이 코드로 합성(야옹, 쿵, 쨍그랑, 휴지, 발톱, 열쇠, 문).
- 작은 소품(컵·접시·꽃병·휴지·사과·신발·액자)과 로봇청소기는 도형 조합.
