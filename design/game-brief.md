# Game Brief: 마왕님은 바쁘다

**One-sentence pitch:** 던전을 짓고, 몬스터를 키우고, 용사가 쳐들어오면 마왕이 직접 나가서 패는 2D 로그라이크.

## Core loop
- **건설:** 방, 함정, 몬스터를 그리드에 배치
- **침입:** 용사 파티가 코어를 향해 진격함. 마왕을 직접 조작해서 몬스터와 같이 싸움
- **보상:** 웨이브를 막으면 3개 중 1개를 고름 (새 방/함정, 몬스터, 몬스터 강화, 마왕 스킬)
- 다음 웨이브는 더 강해짐 → 다시 건설

## Player goal & fail state — what "working" looks like
- 목표: 웨이브 10개를 버티고 마지막 용사 보스를 잡기
- 실패: 던전 코어 HP가 0이 되면 런 종료, 처음부터. 죽은 몬스터는 그 런에서 영구 손실

## MVP — what must exist to be the game
1. 그리드 던전 맵 + 방/함정 배치 (건설 페이즈)
2. 용사 AI: 경로를 따라 코어로 진격하고, 막히면 싸움
3. 마왕 직접 조작 전투 (하데스식): WASD 이동 + 대시(무적), 근접 휘두르기(메인 딜), 마우스 조준 마법탄(탄 3발, 시간 지나면 충전)
4. 몬스터 3종 배치 + 자동 전투. 죽으면 영구 손실
5. 웨이브 10개 + 마지막 용사 보스
6. 웨이브 보상: 3개 중 1개 선택 (몬스터 강화 = 키우기 요소)
7. 코어 HP + 런 종료 / 재시작

## Out of scope — not building this
- 메타 업그레이드 (다음 런으로 넘어가는 영구 강화). MVP가 재밌으면 1순위로 추가
- 몬스터 진화와 스킬 트리, 임프 채굴 같은 자원 경제
- 스토리, 세이브, 여러 맵, 멀티

## Build order
1. 마왕 조작(대시·근접·마법탄) + 용사 1명 전투 (재미 검증이 제일 위험해서 첫 번째)
2. 그리드 맵 + 몬스터 배치 + 자동 전투
3. 함정/방 배치 + 용사 길찾기
4. 웨이브 + 보상 3택 1
5. 코어 HP + 런 종료 + 영구 손실

---
**Who it's for / what they feel:** 짧은 런을 좋아하는 로그라이크 팬. "내 던전이 용사를 갈아버리는" 쾌감.

**Art & audio direction:** Enter the Gungeon 스타일. 탑다운 3/4 시점 16x16 픽셀아트, 어두운 석조 던전 + 강한 발광 이펙트(레이저, 횃불, 탄막), 화면 흔들림·히트스톱으로 타격감. 칩튠 BGM.

**Reference game:** Dungeon Keeper. 방 배치와 몬스터로 침입자를 막는 부분만 가져옴. 임프 경제, 영지 정복은 제외.
