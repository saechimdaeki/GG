# Game Brief: 저주받은 전당포

**One-sentence pitch:** 마계 뒷골목 전당포 주인이 되어, 몬스터 손님이 가져온 수상한 물건을 돋보기·저울·촛불로 감정해 가짜와 저주품을 골라내고 흥정으로 7일 안에 빚을 갚는 감정 퍼즐 상점 심.

## Core loop
- **손님 입장:** 몬스터가 물건 하나를 내밀고 사연을 말함 ("할머니 유품인데요…")
- **감정:** 도구 3종으로 단서를 찾고 손님 말과 대조 → 진품 / 가짜 / 저주품 판정
- **흥정:** 매입가 제시. 손님 성격(급함·깐깐함·거짓말쟁이)에 따라 수락/역제안/퇴장
- **하루 정산:** 산 물건 되팔기 → 수익, 저주품은 밤에 효과 발동 → 빚 상환, 다음 날 손님은 더 교묘해짐

## Player goal & fail state — what "working" looks like
- 목표: 7일째 밤까지 빚 1000골드를 전부 갚기
- 실패: 7일째에 빚이 남았거나, 저주 게이지가 가득 차면 가게가 저주에 먹혀 런 종료

## MVP — what must exist to be the game
1. 카운터 한 화면 + 손님 등장·대사·퇴장
2. 물건 생성기: 재질·각인·무게·저주를 데이터로 조합해 진품/가짜/저주품 생성
3. 감정 도구 3종: 돋보기(각인·흠집), 저울(무게 vs 재질), 촛불(저주 반응)
4. 흥정: 가격 제시 → 수락/역제안/거절, 손님 성격 3종
5. 하루 정산: 되팔기 수익, 저주품 밤 효과, 저주 게이지
6. 7일 진행 + 빚 + 승리/패배 화면

## Out of scope — not building this
- 도구 업그레이드 트리, 메타 진행
- 가게 꾸미기, 진열대 배치
- 단골 손님 스토리 분기
- 저장/이어하기
- 다국어, 음성

## Build order
1. 물건 생성기 + 돋보기·저울로 "이거 가짜다" 잡아내는 장면 하나 (재미 핵심 검증)
2. 흥정
3. 손님 입장→감정→흥정→퇴장 흐름
4. 촛불 + 저주품 + 하루 정산
5. 7일·빚·승패
6. 연출 (조명, 사운드)

---
**Who it's for / what they feel:** 관찰·추리를 좋아하는 솔로 플레이어, 한 판 30~40분, "잡았다, 가짜!"의 쾌감.

**Art & audio direction:** 촛불 하나 켜진 어두운 도트 가게, 물건은 큼직한 클로즈업. 빗소리, 문 종소리, 낮은 재즈풍 BGM.

**Reference game:** Papers, Please — 한 화면 대조 + 하루 정산 루프만. 가족 부양·정치 시스템 없음.
