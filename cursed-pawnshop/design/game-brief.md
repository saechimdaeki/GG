# Game Brief: 저주받은 전당포

**One-sentence pitch:** 마계 뒷골목 전당포를 물려받은 주인이 되어, 괴물 손님들과 말싸움하고 수상한 물건을 감정하고 흥정하며 30일 동안 고리대금업자의 빚을 갚는 — 손님들이 내 행동을 기억하는 감정·장사 시뮬레이션.

## Core loop
- **🌅 아침:** 편지·소문 읽기, 오늘 금속 시세 확인, 진열대 정리·가격표, 상점에서 도구·가구 구매 → 가게 열기
- **☀️ 낮:** 손님 응대
  - 파는 손님: 대화(질문) → 감정(돋보기·저울·…) → 추궁 → 흥정 → 매입/거절
  - 사는 손님: 진열품 보고 흥정 → 판매
  - 사건 손님: 경비대 수배품 조회, 도둑맞은 물건 주인, 저주 수집가, 복수하러 온 괴물
- **🌙 밤:** 정산, 저주품 밤 사건, 세공(가짜 녹여 금속 회수·진품 수리), 빚 상환, 일기 → 다음 날

## 괴물들은 기억한다 (관계·이벤트)
- 손님은 명부에 있는 단골 괴물들. 각자 성격(정직/급함/사기꾼/…)과 **호감도**가 있음
- 헐값을 부르거나, 억울하게 추궁하거나, 거래를 걷어차면 원한이 쌓임 → "두고 보자" → 며칠 뒤 **복수 이벤트**(유리창 박살, 물건 훔침, 저주 걸기, 나쁜 소문으로 손님 감소)
- 잘 대해주면 호감 → 선물, 귀한 물건 우선 거래, 사기꾼 정보 귀띔
- 그 외 랜덤 이벤트: 경비대 단속, 시세 폭등·폭락, 경매, 유령 손님, 정전(촛불만으로 영업)

## Player goal & fail state — what "working" looks like
- 목표: 30일(4주 + 마지막 날) 동안 매주 늘어나는 빚을 갚기. 엔딩 여러 개(빚 청산, 마계 최고 감정사, 장물 조직 보스 등)
- 실패: 주간 상환일에 못 갚으면 가게 차압(배드엔딩). 저주 게이지가 가득 차도 끝
- 하루가 "완성"됐다 = 손님을 다 받고 밤 정산까지 끝나 다음 날 가게를 열 수 있음

## MVP — milestones (each one playable)
1. **M1 하루 순환:** 손님 명부·성격·대화·감정·추궁·흥정, 원한/호감 + 복수 이벤트, 밤 정산, 다음 날
2. **M2 장사:** 진열대 + 사는 손님 + 일일 금속 시세
3. **M3 빚과 성장:** 주간 빚 상환, 상점(도구·가구 업그레이드), 감정 도구 확장
4. **M4 이야기:** 단골 스토리 아크, 사건 손님, 평판·경비대(장물 루트)
5. **M5 저주:** 저주품 + 촛불 + 세공 + 저주 게이지
6. **M6 완성:** 도트 아트(GPT 파이프라인), 사운드, 저장/이어하기, 엔딩들

## Out of scope — not building this
- 멀티플레이, 온라인
- 3D, 가게 밖 마을 탐험
- 음성 더빙, 다국어 (한국어만)

## Build order
1. M1 — 손님과의 대화·흥정이 재밌는지부터 (원한 이벤트 포함)
2. M2 → M3 → M4 → M5 (경제가 먼저 서야 스토리·저주가 얹힘)
3. M6 — 아트는 각 마일스톤 중간에 GPT 프롬프트로 조금씩 교체 가능

---
**Who it's for / what they feel:** 장사·추리 시뮬을 좋아하는 솔로 플레이어. "이 고블린 또 거짓말하네", "저번에 깎았던 오크가 복수하러 왔다!"

**Art & audio direction:** 촛불 조명의 어두운 16비트 도트 가게, 큼직한 괴물 초상화(표정 변화). 빗소리, 문 종소리, 낮은 재즈풍 BGM.

**Reference game:** Papers, Please(대조·하루 정산) + Moonlighter의 가게 운영(진열·가격) + 괴물 손님의 관계 기억은 이 게임만의 것.
