# 플레이테스트 체크리스트 — 유령집 이삿짐센터

한 판 약 15분 (3일 × 5분). 2~4명. 끝나고 5분 동안 바로 적기.

## 준비 (5분)

1. 호스트: `godot -- --host` (또는 빌드 앱 → 메뉴 "호스트")
2. 참가자: 메뉴에 호스트 IP 입력 → "참가" (같은 와이파이, 포트 7777)
3. 화면 녹화 켜기 (웃긴 장면 = 트레일러 소재)

## 관찰 — 보이면 체크

**같이 들기 (핵심)**
- [ ] 소파를 둘이 들 때 누가 먼저 "잠깐잠깐!" 같은 소리를 냈다
- [ ] 현관에서 소파를 돌려야 한다는 걸 말 안 해도 알아냈다 (몇 초 걸렸나: ___)
- [ ] 계단으로 옷장을 내렸다 / 포기했다
- [ ] 누가 가구를 떨어뜨려서 웃었다

**저주·유령**
- [ ] 옷장이 도망가는 걸 보고 반응했다
- [ ] 피아노에 튕겨났을 때 짜증 vs 웃음: ___
- [ ] 유령 때문에 가구를 버리고 도망쳤다
- [ ] 전원 기절로 하루를 날렸다 (몇 번: ___)
- [ ] 퇴마 테이프를 샀다 / 썼다

**런**
- [ ] 1일차 할당량(250원) 달성 여부: ___
- [ ] 상점에서 뭘 샀나: ___ — 이유: ___
- [ ] 3일 끝까지 갔다 / 중간에 그만했다 (언제: ___)

## 끝나고 묻기 (각자 한 줄)

1. 제일 웃겼던 순간?
2. 제일 짜증났던 순간?
3. 한 판 더 할래? (예/아니오)
4. 이거 5~8달러면 친구랑 살래?

## 판정

- **계속:** 3번 질문에 절반 이상 "예" + 웃긴 순간이 판마다 나옴
- **고치기:** 웃긴 순간은 있는데 짜증 > 웃음 → 짜증 원인 1개만 고치고 다시
- **방향 전환:** "한 판 더" 없음 → 같이 들기 손맛부터 재검토

결과는 `/playtest-report`로 정리.
