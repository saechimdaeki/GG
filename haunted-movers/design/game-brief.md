# Game Brief: 유령집 이삿짐센터 (Haunted Movers)

**One-sentence pitch:** 친구 2~4명이 이삿짐센터 직원이 되어, 매일 모양이 바뀌는 귀신 들린 저택에서 고물을 건져 트럭에 싣고 몬스터를 피해 시간 안에 빠져나오는 협동 호러 게임.

## Core loop
- 트럭이 저택 앞에 섬 (제한 시간 7분, 4분 뒤 정전)
- 현관으로 들어가 어두운 방을 뒤지며 스캔(우클릭)으로 고물과 값 확인, 4칸까지 줍기 — 깊이 갈수록 비싸지만 몬스터가 늘어남
- 트럭 짐칸에 내려놓기 — 욕심낼지, 지금 돌아갈지
- 번 돈으로 장비(강력 손전등·운동화·퇴마 테이프) → 다음 할당량

> 2026-11-17 개편: 물리 가구 끌기는 재미가 없어서 폐기. 가구는 저택 내부의 장식(먼지 덮개)으로만 남음.

## Player goal & fail state — what "working" looks like
- 목표: 할당량 이상 보수를 벌고 출발
- 실패: 유령에게 처음 잡히면 4초 기절, 같은 날 두 번째면 사망(관전). 몬스터는 닿으면 사망. 트럭이 떠날 때 못 탄 사람도 사망. 전원 사망 → 이번 할당량 기간에 모은 돈 전부 잃음. 3일 마감 할당량 미달 → 해고(런 종료). 할당량은 달성할 때마다 커짐(끝없음)

## MVP — what must exist to be the game
- 1인칭 3D 플레이어: 이동·줍기·물리 들기 (둘이 들면 무거운 게 가벼워짐)
- 2~4인 온라인 협동 (Steam 로비)
- 유령집 1채 + 가구 6종 (저주 행동 2종)
- 트럭 적재: 칸 격자 + 파손 반영 보수 계산
- 유령 1종: 순찰, 들고 있는 사람 방해
- 상점 아이템 3개 + 할당량 3일 런

## Out of scope — not building this
- 집 자체의 절차적 생성 (집은 손으로 만든 1채 — 대신 지하 창고 미로는 매일 생성)
- 근접 음성 채팅, 스킨 커스터마이징, 싱글용 AI 동료
- 콘솔, 런 간 저장

## Build order
1. 둘이서 물리 가구 하나 같이 들기 — 온라인 동기화 (가장 위험, 웃기면 진행)
2. 트럭 적재 + 점수
3. 집 1채 + 가구 6종
4. 유령 AI
5. 상점 + 할당량 런

---
**Who it's for / what they feel:** 디스코드에서 친구랑 싸게 웃고 싶은 사람들 — "야 그거 놓지 마!!"

**Art & audio direction:** 로우폴리 3D, 따뜻한 VHS 색감, 가구에 붙은 귀여운 얼굴. 엘리베이터 재즈가 유령 등장 시 뒤틀림.

**Reference game:** Lethal Company(리썰 컴퍼니) — 죽음·관전, 떠나는 트럭, 전멸 시 손실, 끝없이 커지는 할당량 규칙. R.E.P.O. — 물리 운반. 이름·캐릭터·그림·맵은 가져오지 않음. 전투 없음, 대신 트럭 적재 퍼즐. 리썰식 구조: 매일 바뀌는 지하 미로 + 비상구, 행동이 다른 몬스터(보면 멈춤 / 천장 낙하 / 돌진)가 시간 따라 늘어남 — 몬스터 이름·모습은 우리 것.
